# 제22대 국회의원 선거(2024)
유튜브 정치 댓글 데이터를 기반으로 감정분석을 수행하고, 정당별 긍정·부정 여론 비율을 활용해 국회의원 선거 결과를 예측한 프로젝트입니다.  
댓글 텍스트를 수집·전처리한 뒤 감정 점수를 계산하고, 이를 선거 예측 모델의 주요 변수로 사용했습니다.

## 프로젝트 개요

본 프로젝트는 온라인 댓글 여론이 실제 선거 결과와 어떤 관계를 가지는지 분석하기 위해 진행되었습니다.  
2020년 총선 댓글 데이터를 기반으로 감정분석 및 정당별 라벨링을 수행하고, Random Forest 모델을 활용해 제22대 국회의원 선거 결과 예측에 적용했습니다.

## 주요 기능

| 단계 | 파일 | 설명 |
|---|---|---|
| 댓글 수집 | `youtube_crawling_auto.py` | 유튜브 영상 댓글 데이터 수집 |
| CSV 병합 | `combine_file.py`, `combine_file2.py` | 디렉토리 내 여러 CSV 파일 통합 |
| 정당 라벨링 | `csv_labeling_1.py`, `csv_labeling_2.py` | 댓글 또는 영상 데이터를 정당별로 분류 |
| 텍스트 전처리 | `data_preprocess.py`, `data_preprocess_grammer.py` | 한글 댓글 정제, 불용어 제거, 형태소 기반 전처리 |
| 감정분석 | `emotion1.py`, `emotion2.py` | 댓글의 긍정/부정 감정 분석 |
| 데이터셋 | `reply_2020.csv`, `reply_all.csv` | 2020 총선 및 2024 총선 관련 댓글 데이터 |
| 예측 변수 생성 | `PosNeg_Vote Rate` | 정당별 긍정·부정 비율과 득표율 관계 분석 |
